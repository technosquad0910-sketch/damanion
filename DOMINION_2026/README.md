# DOMINION 2026 — Frontier Command

Футуристическая стратегия в реальном времени. Работает в браузере, не требует собственного сервера и сохраняет прогресс локально.

## Запуск в VS Code
1. Распакуйте папку `dominion_2026`.
2. Откройте её в VS Code.
3. Откройте `index.html` в браузере. Для удобства можно использовать расширение **Live Server**.
4. Для начала кампании постройте энергоузел и казарму, затем обучите разведчика.

## Управление
- ЛКМ по объекту на карте — выбрать.
- Shift + ЛКМ — добавить/убрать объект из выделения.
- ПКМ по карте — отдать выбранным войскам приказ перемещения.
- Кнопки `1`–`5` — быстрый доступ к разделам.
- `Space` — пауза/продолжить.
- `Esc` — закрыть окно.
- `+` / `−` на карте — масштаб.

## Механики прототипа
- Экономика: кредиты, энергия, сплав.
- Строительство: энергоузел, экстрактор, синтезатор, казарма, турель, научный комплекс.
- Войска: разведчик, штурмовик, тяжёлый шагоход.
- Исследования: боевые алгоритмы, автоматизация, композитная броня.
- Бой в реальном времени, перемещение, атаки, вражеские подкрепления.
- Кампания с директивами и песочница.
- Автосохранение в `localStorage`, ручное сохранение и экспорт JSON.

## GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите в репозиторий `index.html`, `style.css`, `game.js` и `README.md`.
3. В репозитории откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем Save.
5. После публикации откройте адрес, который покажет GitHub Pages.

## Windows-приложение
Можно позже упаковать игру через Electron. Это потребует Node.js и отдельной конфигурации упаковки; сама браузерная версия сервер не требует.

## Примечания
- Сохранения хранятся отдельно в каждом браузере и на каждом устройстве.
- Внешний шрифт загружается из Google Fonts; если нужна полностью офлайн-версия, замените его системным шрифтом в `style.css`.
- Это играбельный прототип 0.1. Для дальнейших этапов стоит добавить полноценный pathfinding, размещение построек мышью, более глубокую кампанию, звуки и оптимизированные спрайты.
